Écran du hall Installation pour un nouvel immeuble

Environ 15 minutes. Il faut un compte Google et un compte GitHub (gratuits).

1 Copier le site sur GitHub

  1. Connectez-vous à GitHub, ouvrez le dépôt d'origine et cliquez sur Fork, puis Create fork.
  2. Dans votre copie : Settings › Pages, Source Deploy from a branch, branche main, dossier / (root), Save.
  3. Après 1 à 2 minutes, le site est en ligne à l'adresse https://<votre-compte>.github.io/<nom-du-dépôt>/. Ouvrez-y cette même page d'installation (…/installation.html) pour la suite.

2 Créer le Google Sheet de l'immeuble

Cliquez sur faire une copie du modèle : un Google Sheet avec les trois onglets actus, infos et config est créé dans votre Google Drive.

Créez un Google Sheet avec trois onglets nommés exactement actus, infos et config, et importez-y les modèles data/actus.csv, data/infos.csv et data/config.csv du dépôt (Fichier › Importer).

Puis Partager › Accès général : « Tous les utilisateurs disposant du lien » (Lecteur). Ajoutez les membres du conseil syndical en éditeurs.

Dans l'onglet config, renseignez au moins nom_residence et adresse. Pour la météo, ajoutez les lignes latitude et longitude de l'immeuble (clic droit sur l'immeuble dans Google Maps pour les obtenir).

3 Vérifier le Google Sheet

    4 Adresse à ouvrir sur la tablette

    Indiquez cette adresse comme page de démarrage dans le logiciel de kiosque de la tablette. Vous pouvez aussi scanner le QR code avec la tablette.

    5 Recevoir les mises à jour

    Quand le site d'origine est amélioré, ouvrez votre copie sur GitHub et cliquez sur Sync fork › Update branch. La tablette prend la nouvelle version au rechargement de 3 h du matin.

    Ne modifiez pas les fichiers de votre copie : tout ce qui est propre à l'immeuble est dans le Google Sheet et dans l'adresse de la tablette. Ainsi, la synchronisation se fait toujours sans conflit.
